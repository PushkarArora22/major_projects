
# Job Application Tracker

A Python command-line application for managing and tracking job applications using SQLite.

## Features
- Add, list, search, update, and delete applications
- Store company, role, location, status, date, and notes
- Track statuses: Applied, Assessment, Interview, Offer, Rejected
- View application statistics
- Persistent SQLite storage

## Technologies
Python, SQLite, SQL, CLI

## Run
```bash
python Job Application Tracker.py
```

The SQLite database is created automatically on first run.
