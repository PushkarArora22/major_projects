# Personal Finance & Expense Analytics System

A Python command-line application for recording, categorizing, and analyzing personal income and expenses using SQLite.

## Features
- Record income and expenses
- Categorize transactions
- Store dates and descriptions
- Generate monthly income, expense, and balance summaries
- Analyze expenses by category
- Export transaction data to CSV
- Persistent SQLite storage
- Input validation

## Technologies
Python, SQLite, SQL, CSV, CLI

## Run
```bash
python Personal_Finance.py
```

The SQLite database is created automatically on first run.
